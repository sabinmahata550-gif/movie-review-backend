# MovieMind 🎬

MovieMind is a movie discovery and recommendation platform designed to help
users discover movies based on their interests, preferences, mood, and
watching behavior.

## Project Goal

The goal of MovieMind is to create a real-world movie discovery platform
rather than a simple college project.

## Core Features

- User authentication
- Movie discovery
- Movie search
- Movie details
- Watchlist
- Watched movies
- Ratings
- Reviews
- Personalized recommendations
- Mood-based discovery
- Admin dashboard
- Analytics
